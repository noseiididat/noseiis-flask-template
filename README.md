# What is this?
Basically, this repository mostly is a template of an ___web application___ which has a pre-definied **back-end** and **front-end** _(separated optional use file)_ implemented.

> [!WARNING]
> The __front-end__ file isn't required to make the __back-end__ work, the only thing that has to be noted is that you ___MUST___ add a _name_ tag into your form and define it with "username" for the Username input and "password" with the Password input.
> 
> `<form action="server-ip" method="the method here"><input type="text" name="username" placeholder="Username"></input><input type="password" name="password" placeholder="Password"></input>"</form>` 

# What's the purpose of this?
Help those who aren't so familiar with **back-end** to build their application more easily and eventually let other people commit changes on it if needed for future upgrades _(since this is just a template)_
