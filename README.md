# What is this?
Using few words, this repository mostly is a template of an ___web application___ which has a pre-definied **back-end** and **front-end** logic implemented.

> [!WARNING]
> The front-end file isn't required to make the __back-end__ work, the only thing that has to be noted is that you MUST add a *name* tag into your form and define it with "username" for the Username input and "password" with the Password input. `<form><input type="text" name="username" placeholder="Username"></input><input type="password" name="password" placeholder="Password"></input>"</form>` 

# Main purpose?
Help those who aren't so familiar with **back-end** to build their application more easily and eventually let other people commit changes on it if needed for future upgrades _(since this is just a template)_
